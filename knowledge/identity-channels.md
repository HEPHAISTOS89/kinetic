# Where identity lives in an app

An app is operated, not looked at once. Its identity must survive the
hundredth use and never cost a task. Kinetic's rule:

**Native frame, owned content.** Navigation, controls, system sheets, back
gestures, text fields, permission flows and recovery paths stay native per
platform (that is why critics score Kinetic's native fidelity 4–5). Identity
lives in the channels below — and must reach at least four of them.

| Channel | What carries identity | Minimum |
|---|---|---|
| Display voice | the dealt display face on verdicts, titles, numerals | every screen's top element |
| Field colour | one large colour field (hero band, state field, today column) in the dealt proportion | the first viewport |
| Drawn vocabulary | 6–10 marks from the inventory replacing generic parts | ≥ 4 sites incl. the hero |
| Composition | the dealt engine's first-viewport geometry | the home screen |
| Copy voice | sentences from the user's side of the verb, in the product's register | hero, empty, error |
| Live thing | one direct manipulation made from the idea | one per product |
| Motion personality | the dealt springs + one signature transition | state changes |

## Volume by surface
- **Operate surfaces** (home, lists, detail, forms): voice + field + vocabulary
  + composition. Controls stay system.
- **Moment surfaces** (onboarding, empty, first success, offline, paywall,
  widgets, the app icon): the vocabulary can grow to illustration size, the
  field can take the whole screen. These are where a stranger meets the brand.
- **Danger surfaces** (errors with money/health, destructive confirms): native
  first, identity only through copy voice. Never let a mark replace a warning.

## Tests
- **Colour-scheme test**: if the product's world shows up only as a colour
  scheme, the move hasn't been found yet — add a mark or a composition.
- **Cover-the-logo test**: cover the name on the home render; could you tell
  which product this is from what is left? Name the element that tells you.
- **Hundredth-use test**: will the signature still help on the hundredth
  open? If it only charms once, move it to a moment surface.
