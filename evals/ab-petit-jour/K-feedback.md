# Kinetic — candid feedback from this run (create, D2, React Native)

Ordered roughly by impact.

1. **`kinetic export --stack react-native` emits a type that does not compile in strict RN.** `footnote: {..., fontVariant: ['tabular-nums'] as const}` is a `readonly` tuple; RN 0.81's `TextStyle.fontVariant` is a mutable `FontVariant[]`, so spreading the token into a `style` fails `tsc --strict`. I had to rebuild text styles in a hand-written `design/theme.ts`. The export also drops `system.type.families` entirely (no fontFamily anywhere), drops `data` colours from `useTokens()`, and has no notion of per-platform families (`ui-serif` on iOS vs `serif` on Android) — so the "tokens first" step of kinetic-code produces a file that cannot be used as-is.
2. **`kinetic export --out design/` fails if the folder does not exist** (`[Errno 2] No such file or directory`) instead of creating it. Minor, but it is the documented first step.
3. **`kinetic init` without `--stack` writes `stack: mixed` into config and a KDL skeleton with `stack: mixed`**, even though the router tells you to infer the stack. A brief-only project (no package.json) can't be detected; the hint is printed but the files are left wrong.
4. **D13 in `validate` counts `on-danger` as a saturated accent.** The exemption list covers `danger/success/warning/error/info` but not their `on-*` partners; a dark `on-danger: #3A0B07` tripped "2 saturated hue families exceed the budget (1)" (major). I desaturated it to pass rather than because it was wrong.
5. **D17 (off-grid spacing) cannot tell optical alignment from magic numbers.** Centring a 13/18 footnote on a 32 pt timeline node needs 7 pt; a 2 pt gap between stacked labels is a deliberate half-step. The scanner flagged them as major. I rewrote them as computed values (`(NODE − lineHeight)/2`, `space.xs / 2`), which is better code, but it also means the lexical scan simply no longer sees them — the rule is easy to satisfy without changing a pixel.
6. **K21 only checks `above_fold` requirements whose element appears in `reading_order`.** My R5 (`pickup-row`, above_fold) is nested inside the now card and not in the order list; nothing was reported, so the check silently passes for nested elements.
7. **`validate` rejects a 2 400 ms breathing cycle (K14 "duration outside 60–1200")**. Ambient "live" indicators (a pulse on an ongoing activity — the iOS `.pulse` idiom the platform file itself recommends) legitimately run longer; I had to express it as 1 200 ms "each way". The rule could exempt `kind: signature` loops with a reduce-motion path.
8. **kinetic-motion and the RN stack file assume Reanimated / gesture-handler / expo-haptics.** With only `react-native` available (a common constraint in brownfield or eval setups) there is no guidance for the core `Animated` API (`useNativeDriver`, `AccessibilityInfo.isReduceMotionEnabled`) and no fallback for haptics — the KDL requires a haptics map that cannot be implemented.
9. **No guidance for previewing Dynamic Type in static renders.** kinetic-critique asks for "largest text size" renders, but react-native-web ignores `fontScale`. I added a preview-only `PreviewTextScale` context; a documented pattern (or a note that the XXL check must be marked unjudged) would help.
10. **`kinetic scan` treats fixture artwork as theme leakage.** A placeholder photo drawn in SVG (in `fixtures/photoArt.tsx`) produced D13 "hard-coded colors outside the theme" (minor, inferred); only `fixtures/petitJour.ts` was recognised as a fixture. Fixture detection by folder name would avoid it.
11. **`states code` evaluated nothing** ("data_screens=0; screens_not_evaluated=1") because the screen receives its data through props; the output says so honestly, but the step adds no evidence for prop-driven screens.
12. **The critique module requires an independent critic agent but this setup forbids launching agents**; the self-critique protocol is clear, but `score` then caps at `ship-pending` regardless — expected, worth stating up front in the router for agent-less runs.
13. **Knowledge gaps for this sector.** `sectors.md` has no "childcare / family logistics" entry; I combined Health (riskiest moment: fever) and Messaging. directions.md has no direction for "liaison notebook / caring institution", which is a common product type; Editorial Serif + Clinical Calm was the closest blend.
14. **Brief vs router reading list.** The D2 list is long (8 skills + 7 knowledge files + KDL.md); `taste-rubric.md` is listed only for D3 but kinetic-critique says to "judge against the rubric anchors", so it is effectively required at D2 too.
