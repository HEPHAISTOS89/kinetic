# Kinetic v1.8 — candid feedback from this run (Tern, RN home, studio/create/D2)

1. **Author-before-deal order is contradictory.** kinetic-direct says to write direction A *before* seeing the deal. The studio protocol step 1 says "think → `kinetic deal`" and step 2 asks director 1 to develop "your authored direction A". I ran the deal before writing A down; A already existed in my head, but the engine cannot enforce or record the order.
2. **The director agent rejects authored directions.** agents/kinetic-director.md says "If there is none [deal], say so and stop: directions are dealt, not imagined". Yet the studio sends it the authored A. The agent had to be told explicitly to treat A as its option.
3. **The panel converges on the same 3/4 grid every loop.** Three loops gave identical medians (3.89), and layout_craft stayed at 3 every time even as concrete issues were fixed. The critics re-find new gaps each time. "4 = beats the rival by ≥1" plus "most first drafts are 2–3" makes 4 the ceiling in practice. `score` then demands a judged mean of ≥ 4.0, which one stuck 3 blocks. The ship gate is effectively unreachable in 3 loops.
4. **The critics contradict each other across loops, and the protocol forbids checking.** In loop 2 the identity critic said the light dark-mode button glares, so I made it an outlined surface-2 button. In loop 3 all three critics penalised that change as contradicting the KDL. Gate tallies in the form were praised by identity and called glitchy by product, every loop. Because critics never see prior critiques, they cannot know a "fix" answers an earlier critique.
5. **The clarity budget fights the brief and the scroll.** "≤ 45 words in the first viewport" is unreachable on a home that must show date, window, tide, weather, sections, a signed note and an action (we ended at ~62). The tool counts scrolled previews (a data table) as "first viewport" (it flagged 110–150 words). Cutting the tide band from the done state raised that render's clarity score; critics then penalised the same state for losing the thesis object. The clarity metric and the panel pull in opposite directions.
6. **The `kinetic sheet` default output lands in the cwd.** It wrote `contact-sheet.png` to the project root. Next to a harness that renders into ./shots, it would be easy to pollute shots. The default should be under `.kinetic/`.
7. **`kinetic export` writes `fontFamily: 'DIN Alternate Bold'` (the KDL family string).** RN on Android needs one family name per file, and the harness derives the family from the file name. I had to rename the .ttf files to match. Neither knowledge/stacks/react-native.md nor `export` mentions this. The `board` family key in `families` is accepted but silently unused.
8. **The haptics guidance mismatches a bare-RN sandbox.** The stack file says to map haptics to `none` when no package exists. But `validate` never asked, and the KDL template pre-fills `select: selection`. Nothing checks that KDL haptics are implementable with the allowed imports.
9. **Directions validation never checked that A had no engine.** K29 only rejects a chosen engine that wasn't dealt. An authored direction with `source: author` and no engine passed silently. That is fine, but undocumented (KDL.md only describes `engine:` on challengers).
10. **The deal fed whole-brief tokens into `brief_words`.** These included harness words (esbuild, chromium, typecheck, componenttype). Weighting a palette by "chromium" is noise; the brief file should be stripped to the product section, or the deal should ignore code/infra vocabulary.
11. **The validator's K07 display-size guide (48pt at level 3) nudged me down from 56 to 48.** That was fine, but the K07 message ("a giant headline as the only idea is a costume") reads as a judgment on a time numeral, which is the answer itself, not a costume.
12. **Scan found almost nothing meaningful.** Its one finding was a 6pt gap off the 4pt grid. It missed real issues the critics caught: an inert "Try again" with no onPress (F02), a dark primary contradicting the KDL role, and a hard-coded 15pt font override. F02 detection only matches `onPress={() => {}}`, not a missing onPress on a Pressable.
