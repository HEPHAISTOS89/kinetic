# Kinetic feedback — Courant home (create, D2)

Ordered by how much each one cost or misled me.

1. **`scan` D13 is a false positive on a correct role-based system (2 × major, slop_density capped at 88).** It counts every hex in the theme files. That includes 7 neutral roles × 2 themes, the data colours (line palette) and the status hues, and it reports "14 neutrals / 6 hue families" as colour chaos. The engine's own comment says "status/data hues are legitimate roles", but the logic never exempts them. The threshold (>6 neutrals across *all* themes) also contradicts its own fix text ("≈6 roles each"). `theme_paths` does not help, and there is no way to declare data colours to the scanner.
2. **`system.color.data` is a dead end.** KDL.md and color.md §8b say transit line colours belong in `system.color.data`, but `kinetic export --stack swiftui` does not emit them, so I hand-wrote `LineColors.swift`. Components cannot reference them either: `fg: $color.data.on-line` gives K03 "does not resolve". So the most important colour pair in a transit app (badge text on line colour) is never contrast-checked by the validator. I checked it by hand with `kinetic contrast`.
3. **The ImageRenderer guidance is missing the trap that cost me a loop.** swiftui.md says to put content in a VStack instead of a ScrollView. It does not warn that a VStack taller than the harness's fixed 852 pt frame is centred, so the top and bottom get cut, and that its rows get compressed: rows overlapped and text was clipped in my first render. The working pattern is `Color.clear.overlay(alignment: .top) { content.fixedSize(horizontal: false, vertical: true) }.clipped()`. It is worth one line in "Rendering for review".
4. **Knowledge and validator contradict each other.** directions.md (Quiet Native) prescribes `largeTitle 34/41 700 0.01`, and the validator then flags it (K07: positive tracking at 34 pt). Also, `kinetic palette "#14181C"` (an ink seed) produced a mid-grey dark accent (#A1A5AA) and `strategy: neutral+accent`. Validate then asked me to declare `strategy: monochrome` (K24). The palette tool does not recognise an achromatic seed.
5. **The self-judged critique is the gate, and it is too easy to swing.** The verdict moved from iterate to ship-pending on a single 3-vs-4 call I made about my own work (native_fidelity). That moves the mean from 3.89 to 4.00. The protocol asks me to critique "from renders before re-reading KDL or code", but that is not possible minutes after writing both. `kinetic score` also prints the header "judged (independent critic)" even when `self_judged: true`, which is misleading in reports.
6. **`kinetic init` stack handling.** On an empty folder it chose `stack: mixed, platforms: [ios, android]`. Re-running with `--stack swiftui --force` rewrote design.kdl but left config.json at mixed/android, so I hand-edited it.
7. **The tertiary-text rule is not enforced.** craft.md says "tertiary text never carries needed information". The validator only checks `text-3/bg ≥ 3.0`, which effectively approves text-3 for 15 pt figures. I first rendered the "missed" departure in text-3 (3.6:1) and only caught it by eye.
8. **Exported reduce-motion is one policy for everything.** `KAnimated` swaps every animation to easeInOut 0.15. A per-animation KDL `reduce: instant` or `keep-feedback-only` is lost in the export.
9. **`states template` adds a default `primary-action` button (accent fill, target 48) to every screen.** That nudges toward a big CTA on screens that should not have one. A departures board has no primary button.
10. **Positive, for balance.** The sectors.md "Transit / timetables" entry was the single most useful input: walk-aware minutes, mode shapes for badges, no map-first home, network-wide banners as slop, and red lines vs closures. The K21 requirements / above-the-fold check also kept Saved visible.
11. **Minor.** The minimum reading for D2 is long (about 2,000 lines across 12 files) before any pixel is placed. A D2 "cheat sheet" of the gates (K21, F03–F07, contrast pairs) would save time. The `export --out` directory in my scratchpad already held stale lune exports; export does not say which files in `--out` it did not write.
