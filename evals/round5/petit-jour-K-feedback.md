# Kinetic — candid feedback from the Petit Jour (RN, D2 create) run

Ordered roughly by how much each cost or risked.

1. **`export --out <path>` silently writes a *file* when the directory doesn't exist.** `kinetic export … --out design` printed `wrote design (react-native)` and created a file named `design` (no extension) instead of `design/tokens.ts`. Combined with a cwd mix-up (see 2) it dropped a stray file into another project. It should create the directory, or refuse an extension-less path that isn't a directory.
2. **The engine path has spaces, so everyone writes a wrapper — and the docs suggest one in a shared place.** TOOLS.md recommends an alias/`bash "$KROOT/bin/kinetic"`; in practice agents put a wrapper script in a shared scratchpad, where a parallel run overwrote mine with a `cd` into its own project; my next `validate`/`export` ran against the other project's KDL. A `kinetic` shim with no spaces (or a `--project <dir>` flag that all commands honour and echo) would make this impossible to get wrong. Every command should print the absolute KDL/project path it acted on.
3. **Role names silently decide the accent budget.** A role named `alert` (a deep red fill for the night call button) raised two *major* D13 findings ("2 saturated hue families"); renaming it `danger-fill` made them vanish. Which role names count as status vs accent isn't documented in KDL.md (only the required roles are). Document the status prefix, or allow `status: true` on a role.
4. **`because` and `exceptions` don't quiet `validate`.** I wrote `system.color.because` (blue ink comes from the thesis) and `exceptions` for D01/K26; validate keeps reporting both C findings on every run. Either honour `exceptions` in validate (as scan does) or say in KDL.md that they only apply to `scan`.
5. **K26 compares across themes.** "data color `margin` #E0A79D is close to danger #F08C7C" compares the *light* margin colour with the *dark* danger colour. Compare like with like per theme.
6. **`kinetic init` on a brief-only folder.** It detected stack `mixed`, named the product after the folder (`K`), and didn't accept the stack it suggested in the same breath (`--stack` hint appeared only after creating files). For D2 "create from a brief" the natural first call is `init --stack react-native --name …`.
7. **`svg lint` can't see icons drawn in code.** RN/Flutter/Compose icon sets are usually inline (`react-native-svg` `<Path d=…>`); the lint only reads `.svg` files, so I had to write a throwaway extractor to lint my set (it then caught off-grid values and a radius mismatch — useful!). Accept TSX/Dart/Kotlin path data, or document an extraction recipe.
8. **RN export gaps.** No screen margins (`system.space.margins`) or hairline in the exported tokens; `Platform` is imported and unused; `useTokens()` has no text-scale hook, so every project re-implements one for the XXL preview the RN stack file itself recommends.
9. **`states code` evaluated nothing.** `screens_not_evaluated=1` for a screen whose data arrives as a `Load` union prop (`ready | loading | error`) — the most idiomatic RN shape. The tool added no signal here.
10. **`scan` on RN is thin.** It flagged one `paddingHorizontal: 5` but none of the many literal sizes (10, 18, 36, 56…), and counted `system_coherence` colour at 0.12 in `score` without saying which values drove it (I had to guess it's the SVG/inline colours).
11. **Self-critique gate is hard to read honestly.** `score` gates `ship-pending` on a *self-judged* mean ≥ 4.0 while the critique skill says self-judgment runs 0.5–1 point high and caps distinctiveness at 3 by rule. Following both rules strictly makes `iterate` the expected end state of every agent-less run; say so, or let the cap apply automatically.
12. **Reading load for D2 is heavy.** The D2 minimum list is ~2,000 lines (8 skills + 8 knowledge files + KDL.md). Most of it was valuable (sectors §Childcare and states §3c directly shaped the fever and lag states), but the router could point to the 10 rules that most often decide D2 outcomes first.
13. **Font guidance vs. the RN sandbox.** typography.md recommends New York for the voiced serif, but in an RN project without `expo-font` (and with fonts limited to what can be bundled) there's no guidance on picking a fallback or on old-style vs lining figures in serif heroes (Georgia's old-style "13 h 05" bounces).
14. **Small doc mismatch.** The RN stack file says "SafeAreaProvider at root"; harness-style previews forbid adding one. Worth a line: "previews provide insets; don't nest a provider".

What worked well: the sector playbook for childcare and states.md §3c ("unknown is not 'didn't happen'", "an alert takes over the screen's meaning") produced the two best decisions of the screen; `kinetic palette`/`contrast` were fast and right; the KDL `requirements` + states matrix kept 14 states honest.
