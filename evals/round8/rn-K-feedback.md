# Kinetic v1.8 — candid feedback from this run (studio, create, D2, React Native)

## Top issues
1. **`kinetic clarity` punishes the identity it asks for.** One large colour field (identity-channels.md says it is required in the first viewport) reads as "non-quiet rows". The same layout scored 63 in light and 70–72 in dark. Pencil rings, part-tab glyphs and SVG marks get counted as extra "text sizes": it reported 7, there were really 5. The editor and all three critics said independently that the numbers were partly wrong. But `score` hard-gates `ship` at clarity < 70 and caps layout_craft at 3, so a light-ground design with a dark hero field can't reach `ship` without deleting its hero. The tool needs a field-aware quiet measure and real glyph-height clustering.
2. **The deal fought the brief and the medium.** Option 1 dealt the `one-question` engine: one full-screen question per step for a *home screen* that must answer 3 glance questions. It also dealt a cool navy/cerulean "Night school" palette for a brief whose tone is "warm". The docs claim the deal is weighted by tone. Option 2 (score-sheet) was judged not viable on usability by its own director. Both challengers ended up as donors, not contenders. A home-screen brief should exclude wizard engines.
3. **`kinetic export` ignores per-weight font files and faux-bolds them.** It emits `fontFamily: 'IowanOldStyle-Bold'` *and* `fontWeight: '700'`, so web and Android synthesise a double bold. The stack file itself says "one family per weight, don't use fontWeight". I had to patch this in `theme.ts`. Exporting a `family` that isn't a file (`Iowan Old Style (bundled)`) also silently produces a broken name.
4. **Studio costs and plumbing are heavy and under-specified.** That's 13 sub-agent runs (3 directors, a rival, 2 editors, 9 critics) for one screen, and each critic JSON is about 5k tokens. The lead must re-type them "verbatim" because agents can only return text. There is no `kinetic panel --from-text` and no way for a read-only agent to write its own file. When the API limit hit mid-panel, the whole loop-2 panel had to be relaunched. The protocol says "re-render → editor → panel" each loop. Running the editor in the final loop would have produced cuts nobody judges, so the rules conflict. I skipped the editor in loop 3.
5. **Critics can't judge motion, and the panel median then misbehaves.** Every critic marked motion "unjudged (no recording)" but still scored it 3 or 4, or omitted it. In loop 2 all three omitted it and the dimension vanished from the panel. In loop 3 the median of [4, 3] became 3. The harness has no way to capture motion (static PNGs only), so the signature move counts against the score however well it is implemented. `panel` should flag dimensions judged by fewer than 3 critics, and Kinetic should say what to do when recordings are impossible.

## Other friction
- The router's D2 reading list is long: think, direct, priors, identity-channels, sectors, states, system, code, clarity, states.md, copy, layout, the platform files, the stack file, KDL.md, craft, critique and taste-rubric. That is more than most D2 jobs need. "The deal sheet" is not a named file (it means `deal --show`).
- `sectors.md` has no music/choir/amateur-ensemble entry. "Community venue" was the closest match, but it is about gyms and pools.
- Authored direction A has no dealt engine. K29 ("chosen engine must be dealt") pushed me to write `engine: score-sheet` because A borrows one component from it, which misrepresents the direction. An `engine: author` value is needed.
- The director agent spec says "Return the KDL block only" and "verdict: proposed". KDL.md only lists chosen/rejected, and the director output can't be pasted into KDL as-is: comments, multi-line axes.
- `kinetic contrast` takes two positional args. Under zsh a `$pair` variable doesn't word-split, and the resulting error ("not a hex color: '#a #b'") doesn't hint at the cause.
- `kinetic sheet` and `kinetic score --renders` on 34 PNGs took more than 2 minutes, which hit the tool timeout twice.
- The D34 scanner flagged my dark accent `#E06A5E` as "terracotta" (fine). But the replacement it pushed me towards (`#EF7F86`) was judged "candy pink" by all three final critics. Nothing in `palette` or `color.md` helps pick a dark-theme version of a deep red that stays the same hue family.
- The critics' "native_fidelity" asks (iOS bar material and blur, large-title collapse) are impossible with the allowed imports and the react-native-web harness. A translucent tab bar rendered badly in the static PNG and I reverted it. Kinetic doesn't tell critics what the harness can't show.
- The `kinetic-system` order says "type → color …" and "systemise the dealt type/palette", but my chosen direction was authored. It's unclear whether an authored direction's type and palette must still come from the library.
- The "preview-only text scale" advice (stacks/react-native.md §9) is useful. `theme` export has no hook for it, so I wrote a context by hand.
- Clarity's word budget (≤ 45) conflicts with a brief that needs three pieces plus composers plus a sectional above the fold. The editor itself said about 50 of the 64 words were must-have running order.
- `kinetic score` gives `ITERATE` with no distinction between "stopped at the loop cap" and "work left". The studio rule "max 3 loops" isn't reflected in the verdict.
